# 第 7 部分 · PTX：把 `mma` / `ldmatrix` / `cp.async` 讲透

前面七讲里，`mma.sync` 一直以"一条字符串"的身份躲在 IR 和 MIR 里。
这一部分我们把它拆开：**每一个字段、每一个操作数、每一个修饰符是什么意思。**

PTX 是这套链路里一个很特殊的位置：

```
它是 LLVM 的"最终产物"（我们的后端到这儿就结束了）
同时它又是 ptxas 的"输入"（另一个编译器的源语言）
```

所以读 PTX 时你要同时带着两个视角：**"LLVM 怎么把它生成出来"** 和
**"ptxas 会怎么理解它"**。
