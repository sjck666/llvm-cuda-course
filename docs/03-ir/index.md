# 第 3 部分 · LLVM IR：逐行读懂优化后的产物

前两部分我们把案例立起来、把前端看穿了。这一部分换个姿势：

> **我们把 `dumps/02-device-O2.ll` 从头读到尾，一句一句说清它为什么长这样。**

目标不是让你背语法，而是让你以后看到**任何**一份 `.ll`，都能在五分钟内回答三个问题：

```
1. 这段代码对应源码的哪一块？
2. 它为什么是这种形状？（前端产生的？还是某个 pass 改的？）
3. 它会怎么落到机器指令上？
```

我们只精读 `mma_tc_manual` 这一个函数——`mma_tc_ldmatrix` 形状一样，
只是多了地址空间和 barrier（那些在前一部分已经讲过了）。
