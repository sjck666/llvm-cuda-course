# 第 8 部分 · SASS：离硬件最近的一层

这是全课程你离硬件最近的一部分。**从这里开始，世界换了主角：**

```
前面七部分的主角是 LLVM（clang / opt / llc）
这一部分的主角是 ptxas —— NVIDIA 的汇编器
```

我们只做三件事：

```
1. 把 PTX 汇编成 cubin，取出 SASS，逐条注释
2. 把 HMMA.16816.F32 的四个操作数彻底拆开，
   回答"A/B/C/D fragment 到底住在哪几个寄存器里"
3. 看清楚 ptxas 在你看不见的地方替你做了多少事
   （循环展开、软件流水、指令合成）
```

| 讲 | 标题 | 你会拿到什么 |
| --- | --- | --- |
| [08-1](08-1-get-sass.md) | 拿到 SASS 与资源用量 | 三条命令、四个数字的含义 |
| [08-2](08-2-sass-format.md) | SASS 格式速读 | 定长编码、谓词、寄存器种类 |
