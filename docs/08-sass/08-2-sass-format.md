# 08-2 · SASS 格式速读

这一讲很短，但很实用：**学会看懂一行 SASS。**

## 一、一行 SASS 长什么样

```
        /*03b0*/                   LDSM.16.MT88.2 R22, [R5] ;
        │                          │              │     └─ 地址操作数
        │                          │              └─────── 目标寄存器
        │                          └────────────────────── 操作码与修饰
        └───────────────────────────────────────────────── 指令地址（字节）
```

| 段 | 含义 |
| --- | --- |
| `/*03b0*/` | **指令地址**（字节偏移），`cuobjdump` 补的注释 |
| 操作码 | `LDSM.16.MT88.2`，可能带若干修饰 |
| 目标操作数 | `R22`（大写 R 是通用寄存器） |
| 源操作数 | `[R5]`（方括号表示访存） |

## 二、为什么地址是 0x10 递增的

```
/*03a0*/  BAR.SYNC.DEFER_BLOCKING 0x0 ;
/*03b0*/  LDSM.16.MT88.2 R22, [R5] ;
/*03c0*/  LDSM.16.M88.4  R16, [R3] ;
```

每次 +0x10 = **128 位 = 16 字节**：

> **SASS 指令是 128 位定长编码。**

这和 x86（变长指令）完全不同。定长的好处是取指、译码简单——
GPU 这种"大量线程执行同一段代码"的场景特别适合。

（`nvdisasm -c -hex` 会打出两行十六进制，每行 64 位，合起来 128 位。）

## 三、谓词：指令前面的 `@`

```
/*00b0*/  @!P0 BRA 0xd80 ;
/*0820*/  @!P1 BRA 0x2c0 ;
```

`@!P0` = "当谓词 P0 为**假**时执行这条指令"。

`P` 开头的寄存器是**谓词寄存器**（1 位，只有真/假）。它们来自比较指令：

```
/*0020*/  ISETP.LT.AND P0, PT, RZ, c[0x0][0x180], PT ;
```

读作："比较 `RZ`（恒零）和常量内存 `c[0x0][0x180]`（也就是 K），
把 `RZ < K` 的结果写进 P0"。紧接着的 `@!P0 BRA` 就是"如果 K <= 0 就跳走"。

**这就是源码里 `if (K > 0) { 主循环 }` 在 SASS 里的样子。**

## 四、寄存器种类

| 前缀 | 是什么 | 例子 |
| --- | --- | --- |
| `R` | 通用寄存器（32 位） | `R16`、`R22` |
| `UR` | uniform 寄存器（warp 内共享的标量） | `UR6` |
| `P` | 谓词寄存器 | `P0`、`P1` |
| `RZ` | 恒零寄存器 | `RZ`（相当于 MIPS 的 `$zero`） |
| `SR` | 特殊寄存器 | `SR_TID.X`、`SRZ` |
| `c[0x0][0x180]` | 常量内存（bank 0，偏移 0x180） | 用来读 kernel 参数 |

**`c[0x0][...]` 这个写法值得记**：kernel 参数住在常量内存里，
所以你会看到"直接从常量内存读 K/N"这种指令（比如 `ISETP` 里那个 K）。

## 五、几个常见的修饰后缀

| 修饰 | 含义 |
| --- | --- |
| `.reuse` | 操作数复用缓存提示（省一次寄存器堆读） |
| `.X` | 带进位链（用于 64 位运算） |
| `.E` | 扩展寻址（64 位地址） |
| `.BYPASS` | 绕过 L1（对应 PTX 的 `.cg`） |
| `.CONSTANT` | 走常量/只读缓存路径（对应 `ld.global.nc`） |
| `.DEFER_BLOCKING` | barrier 的调度变体（让出调度槽而不完全阻塞） |

**这些修饰不是装饰**：`.BYPASS` 和 `.CONSTANT` 直接决定走哪条缓存路径，
而它们都能一路追溯到源码里的选择（`__restrict__`、`.cg`）。

## 六、常见指令家族

| 前缀 | 家族 | 例子 |
| --- | --- | --- |
| `LDG` / `STG` | 全局内存读写 | `LDG.E.CONSTANT R13, [R32.64+-0x10]` |
| `LDS` / `STS` | 共享内存读写 | `LDS RZ, [RZ]` |
| `LDSM` | 矩阵加载（`ldmatrix`） | `LDSM.16.M88.4 R16, [R3]` |
| `LDGSTS` | 异步拷贝（`cp.async`） | `LDGSTS.E.BYPASS.128 [R7], [R32.64+0x20]` |
| `HMMA` | 矩阵乘累加（Tensor Core） | `HMMA.16816.F32 R16, R16, R22, R12` |
| `IMAD` | 乘加（地址计算主力） | `IMAD.WIDE R22, R18, R23, c[0x0][0x168]` |
| `IADD3` | 三操作数加法 | `IADD3 R5, R5, 0x20, RZ` |
| `ISETP` | 比较并写谓词 | `ISETP.GT.AND P1, PT, R20, 0x30, PT` |
| `S2R` | 读特殊寄存器 | `S2R R0, SR_TID.X` |
| `PRMT` | 字节置换 | `PRMT R24, R27, 0x5410, R29` |
| `CS2R` | 读特殊寄存器到两个寄存器 | `CS2R R8, SRZ`（用来清零） |
| `BAR` | 同步 | `BAR.SYNC.DEFER_BLOCKING 0x0` |
| `BRA` | 跳转 | `@!P1 BRA 0x2c0` |
| `DEPBAR` / `LDGDEPBAR` | 依赖屏障（等异步操作） | `DEPBAR.LE SB0, 0x0` |

## 七、小结

1. 一行 SASS = **地址 + 操作码 + 操作数**；指令是 **128 位定长**，地址按 0x10 递增。
2. 谓词写在最前面（`@!P0`）；寄存器分通用 / 谓词 / uniform / 特殊 / 常量内存几类。
3. 修饰后缀（`.BYPASS`、`.CONSTANT`、`.REUSE`…）**直接影响性能行为**，
   而且往往能追溯到源码里的某个选择。
