# 第 6 部分 · NVPTX 后端：把第 5 部分的地图对上真实代码

第 5 部分我们讲了"一套后端应该长什么样"。这一部分我们**回到 NVPTX**，
把那张地图一格一格对上真实文件和真实产物。

为什么还要单独一部分？因为 NVPTX 是个**很特别的目标**：

```
它的目标是一个虚拟 ISA（PTX），不是真实硬件
所以它不做寄存器分配，调度也只做一半
但它的"元信息"特别多（地址空间、param 空间、kernel 标记、虚拟寄存器声明）
所以它的 IR 层 pass 和 AsmPrinter 反而比普通后端更重
```

**理解这个"薄一半、厚一半"的结构，你对后端的理解就完整了。**
