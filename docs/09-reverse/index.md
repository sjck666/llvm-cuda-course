# 第 9 部分 · 反推与实战：给一条新指令做端到端接入

前面八部分我们都是"从源码往下追"。这一部分反过来：

> **假设 `mma.sync` 是目标 ISA 里已经有、但 LLVM 还不认识的一条新指令——
> 你要怎么从零把它接进来？**

这个问题在现实中很常见：

```
你在给一家新硬件厂写后端
你要给 MLIR 里的一个 tensor 方言做 lowering
你发现某个 PTX 指令 LLVM 还不支持，想自己加上
```

这一部分把"接入一条新指令"拆成可执行的步骤，每一步都指到真实源码，
而且**最后一段用真实的实验验证**。

| [09-2](09-2-six-steps.md) | 六步接入法 | 逐文件：intrinsic → 指令 → 内存行为 → 前端 → 测试 |
