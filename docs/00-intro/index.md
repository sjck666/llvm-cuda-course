# 第 0 部分 · 导览

开始之前，先用两讲讲清楚三件事：**这套课到底在追什么、你该怎么读、以及你这台机器上
的版本对不对**。这两讲不讲技术细节，但它们是后面所有推导的前提。

| 讲 | 标题 | 你会拿到什么 |
| --- | --- | --- |
| [00-1](00-1-how-to-use.md) | 这套课怎么上 | 学习路径、每讲的结构、前置知识、常见误区 |
| [00-2](00-2-environment.md) | 环境与工具链 | 版本基线、一条自检命令、以及"版本不同结论就不同"的真实例子 |

读完这两讲，你应该能回答：

- 我为什么要顺着 `.cu → .ll → PTX → SASS` 这条线走一遍？
- 我手上的 clang/LLVM 是哪一版？它和教材里写的对得上吗？
- 遇到"命令跑不出教材里的结果"，第一步该查什么？
